# Galeria de screenshots no README

## Objetivo

Mostrar a versão desktop publicada do Projeto Cronos diretamente no README.

Atualizar a apresentação para informar que o site foi desenvolvido durante o ensino médio integrado ao curso de Análise e Desenvolvimento de Sistemas.

## Conteúdo

- Captura do início da loja.
- Captura do catálogo de produtos.
- Captura da página de detalhes de um relógio.

As imagens terão viewport desktop de 1440 × 900, serão salvas em `docs/screenshots/` e aparecerão em uma nova seção `📸 Screenshots` após o Overview, com legendas curtas e caminhos relativos.

## Verificação

- Confirmar que cada imagem mostra uma área diferente do produto.
- Confirmar que os arquivos PNG abrem corretamente.
- Confirmar que todos os caminhos usados no README existem.
